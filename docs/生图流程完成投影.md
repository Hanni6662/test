# 生图流程完成投影

`completion` 为会话详情及会话历史的可选增量字段。保留原会话交接 `status`，图片业务结果以 Task 为准。

| 字段 | 含义 |
|---|---|
| `task_status` | 当前任务结果，包含成功、部分成功、失败等 |
| `delivery_status` | `pending`、`confirmed`、`unresolved`、`not_applicable` |
| `dify_run_status` | 原 Dify 执行结果，未观察到时为 null；明确接受 `stopped` |
| `reconciliation_status` | `pending`、`unknown`、`completed`、`completed_with_execution_warning` |
| `reason_code` | 受控当前原因码，可为 null |
| `confirmed_count` | 已确认的交付数量 |
| `closed_at` | 对账完成时间，可为 null |

成功图片与异常执行并不互斥。前端继续显示 Task 的实际图片结果，并将执行异常作为收尾提醒；不要把 Dify 的 `stopped` 改写成成功，也不要因历史 Action 曾 unknown 就重复购买或重新生成。

交付核对包含图位/Attempt 映射、原图和预览的资产归属、摘要与大小，以及确认状态。后续重试的当前 Task 不使用初始运行的旧完成快照冒充新任务完成。
