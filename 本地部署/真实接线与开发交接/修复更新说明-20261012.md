# 推荐等待与识图输入修复更新

本次为既有开发包的增量更新。同步推荐持续等待修复与识图消息通信修复，不修改运行中的主 Dify 发布版或草稿，不附带原机器配置、凭证、用户图片、任务记录或工作区数据库。

## 修复内容

1. prepare/deliver 优先消费已经存在的原生 structured_output；保留旧文本兼容与原业务校验。交付的是已有修复后的无密钥 DSL，只有两个消费者节点与旧交付导出不同，连线、模型、提示词与环境变量保持一致；没有在本次同步中重新发布主流程。
2. 后端识别表单到达前的明确 Dify 终态失败。已知 Run 的未知启动最多执行三次只读核实，保留输入摘要和原 Run 绑定，确认终态后解除重试阻塞；未知受理不能盲目重发。
3. audit 明确声称未收到主参考图时，后端拒绝推荐并返回 V34_REFERENCE_NOT_OBSERVED。缺少尺寸、材质证据或辅图等正常未知信息不会因此被误判。
4. Vue 显示推荐失败、核实中、过期和取消的对应提示及可用操作；主图未观察错误提供重新推荐或上传清晰图片的说明。
5. 提供独立图片消息通信补丁与可移植安装器，限定经验证的 OpenAI API Compatible 0.0.68 指定包、claude-sonnet-5-5 和 api.aipaibox.com。仅合并相邻含图片的用户消息，保留内容顺序和角色边界，不修改主流程或模型凭证。安装前核对源码哈希，原文件备份须放在交付目录和插件存储之外；不覆盖不认识的版本或已有自定义 helper。
